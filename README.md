Rock-Paper-Scissors is a classic hand game brought to life using HTML, CSS, and JavaScript. This interactive web app lets players compete against the computer by choosing between rock, paper, or scissors. The game instantly compares choices, displays the result (win, lose, or draw), and updates the score accordingly. With smooth animations and a clean user interface, it offers a quick and fun experience for all ages. The design is responsive, making it enjoyable to play on both desktop and mobile devices.
